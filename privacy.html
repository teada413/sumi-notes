Sumi Notes のプライバシーポリシー

最終の更新日: 2026年10月29日

1. はじめに

Sumi Notes（以下「本アプリ」）は、Windows で動作するノートアプリです。

本プライバシーポリシー（以下「本ポリシー」）は、本アプリにおける利用者の情報の取り扱いについて定めるものです。本ポリシーは、本アプリの公式サイト（以下「本サイト」）に掲載しています。

2. 取得する情報

本アプリは、利用者の情報を収集しません。また、利用者の情報をどこにも送信しません。具体的には、次のことを行いません。

  • 利用状況や操作の記録（アクセス解析・統計）の取得
  • エラーの情報を開発者に送信する仕組み（クラッシュレポート）の利用
  • 広告の表示

本アプリには、アカウントの登録やサインインの機能はありません。

3. 情報の利用目的

本アプリは利用者の情報を取得しないため、利用者の情報を何らかの目的に利用することはありません。

利用者の PC の中に保存するデータ（7. を参照）は、ノートの表示・検索・改訂履歴などの本アプリの機能を提供するためだけに、その PC の中で使用します。

4. 第三者への提供

本アプリは利用者の情報を取得しないため、第三者に提供することもありません。

ただし、5. に記載する外部の画像を取得する際には、画像を配信するサーバーに接続の情報が伝わります。

5. 外部との通信

本アプリがインターネットに接続するのは、次の2つの場合に限ります。

  1. ノートに記載された外部の画像を表示するとき
    • ノートの本文にインターネット上の画像の URL（https: で始まるもの）が記載されている場合、プレビューの表示・PDF の書き出し・印刷の際に、その画像を取得します
    • 取得の対象は、https: で始まる URL に限ります。家庭や社内のネットワークのアドレス（localhost やプライベート IP アドレスなど）からは取得しません
    • 画像を配信するサーバーには、一般的な Web の閲覧と同様に、利用者の IP アドレスなどの接続の情報が伝わります。本アプリが、Cookie やノートの内容を送信することはありません
  2. 利用者がノートの中のリンクを押したとき
    • リンク先を、PC の既定のブラウザで開きます。開いた後の情報の取り扱いは、そのブラウザとリンク先のサイトの定めに従います

これらのほかに、本アプリが自ら外部と通信することはありません。フォントなどの構成要素は本アプリに含まれており、インターネットから読み込みません。

6. クリップボードの利用

本アプリは、「HTML としてコピー」などの操作が行われたときに限り、クリップボードに書き込みます。また、画像の貼り付けなど、利用者が貼り付けの操作を行ったときに限り、クリップボードを読み取ります。

7. 情報の保存場所

本アプリが作成するデータは、すべて利用者の PC の中に保存します。

  • ノート: 利用者が選んだ「ノートのフォルダ」に、Markdown 形式のファイル（.md）として保存します。貼り付けた画像、テンプレート、ゴミ箱、タグの色などのフォルダ全体の設定も、このフォルダの中に保存します
  • アプリの設定など: 配色や文字の大きさなどの設定、全文検索の索引、ノートの改訂履歴、ウィンドウの大きさと前回の画面の状態は、その PC の中のアプリ用の領域に保存します

本アプリが、これらのデータを外部へ送信することはありません。ノートのフォルダを OneDrive などの同期サービスのフォルダの中に置いた場合、そのファイルの取り扱いは、その同期サービスの定めに従います。

本アプリをアンインストールしても、ノートのフォルダとその中のノートは削除されません。

8. Microsoft Store を通じた入手と更新

本アプリの入手・更新・アンインストールは、Microsoft Store と Windows が行います。その際の情報の取り扱いは、Microsoft のプライバシーに関する声明に従います。

9. 本ポリシーの改定

本ポリシーを改定する場合は、本ページを更新し、更新日を記載します。
