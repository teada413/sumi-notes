Sumi Notes Privacy Policy

Last updated: October 29, 2026

This is an English translation of the Japanese privacy policy. If this translation and the Japanese version differ, the Japanese version prevails.

1. Introduction

Sumi Notes (the "App") is a note app that runs on Windows.

This privacy policy (the "Policy") sets out how the App handles information about its users. The Policy is published on the official website of the App (the "Site").

2. Information We Collect

The App does not collect any information about its users. The App does not send information about its users anywhere. Specifically, the App does not do any of the following.

  • Record usage or user actions (analytics or statistics)
  • Use a system that sends error information to the developer (crash reports)
  • Show advertisements

The App has no account registration or sign-in.

3. How We Use Information

Because the App does not collect information about its users, it does not use such information for any purpose.

Data that the App keeps on the user's PC (see 7.) is used on that PC only to provide the features of the App, such as showing notes, search and revision history.

4. Sharing with Third Parties

Because the App does not collect information about its users, it does not share such information with third parties either.

However, when the App gets an image from outside as described in 5., connection information reaches the server that delivers the image.

5. Communication with Outside Services

The App connects to the internet only in the following two cases.

  1. When showing an image from the web written in a note
    • When the text of a note contains the URL of an image on the internet (one that starts with https:), the App gets that image when showing the preview, exporting a PDF or printing
    • The App gets images only from URLs that start with https:. It does not get images from addresses on a home or office network (such as localhost or private IP addresses)
    • As with ordinary web browsing, connection information such as the user's IP address reaches the server that delivers the image. The App does not send cookies or the contents of notes
  2. When the user clicks a link in a note
    • The App opens the link in the default browser of the PC. After that, information is handled under the terms of that browser and of the linked site

Other than these, the App does not communicate with outside services on its own. Components such as fonts are included in the App and are not loaded from the internet.

6. Use of the Clipboard

The App writes to the clipboard only when the user performs an action such as "Copy as HTML". The App reads the clipboard only when the user pastes, for example when pasting an image.

7. Where Information Is Stored

All data that the App creates is stored on the user's PC.

  • Notes: Saved as Markdown files (.md) in the "notes folder" that the user chooses. Pasted images, templates, the trash and settings for the whole folder, such as tag colors, are also saved in this folder
  • App settings and other data: Settings such as the theme and the text size, the full-text search index, the revision history of notes, the window size and the state of the last screen are saved in the App's own storage on that PC

The App does not send this data anywhere. If the user puts the notes folder inside the folder of a sync service such as OneDrive, those files are handled under the terms of that sync service.

Uninstalling the App does not delete the notes folder or the notes in it.

8. Getting and Updating the App Through Microsoft Store

Microsoft Store and Windows handle getting, updating and uninstalling the App. Information involved in these is handled under the Microsoft Privacy Statement.

9. Changes to This Policy

If we change the Policy, we will update this page and show the date of the update.

10. Contact

Please send questions about the Policy to the following email address. We accept questions in English as well as in Japanese.
